# Examples

## `brief/` — business analysis as an audio briefing

A [Claude Code skill](https://docs.claude.com/en/docs/claude-code/skills). Drop it
in `~/.claude/skills/brief/` and ask Claude Code for a business analysis; it
researches, writes the report, rewrites it for the ear, renders it and syncs it to
your phone.

Edit the `cd` path in step 4 to point at your clone. It is here as a worked example
of driving `pod` from an agent — the same shape works for any research-to-audio
pipeline.
